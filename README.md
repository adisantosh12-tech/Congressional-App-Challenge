# StudyBridge — How to Use the App

## Welcome to StudyBridge!

StudyBridge is a student-focused learning platform that helps students connect, collaborate, and improve their understanding of school subjects.

You can find study groups, ask questions, communicate with classmates, and test your knowledge using AI-powered Teach Back.

## 1. Getting Started

No downloads or installations are required!

1. Open the StudyBridge website using its website link.
2. Select **Sign Up** to create an account.
3. Enter your account information.
4. Complete your profile.
5. Start exploring StudyBridge!

If you already have an account, select **Sign In**.

## 2. Explore the Features

### Home
Your main dashboard provides access to StudyBridge's features and helps you navigate the app.

### Find Groups
- Browse available study groups.
- Explore groups by subject or topic.
- View group descriptions and schedules.
- Find groups that match your interests.

### My Groups
- View your study groups.
- Open groups you have joined.
- Manage groups you created.
- Review membership requests.

### Messages
Communicate with other students through group conversations and collaborate on schoolwork.

### Help Board
Need help with something? Use the Help Board!

- Post a question about a school subject.
- Browse questions from other students.
- Offer help to classmates.
- Reply to posts and share knowledge.

### Teach Back
Teach Back helps you test how well you understand a topic by teaching an AI student.

1. Open the Teach Back section.
2. Choose a topic.
3. Explain the topic in your own words.
4. Answer the AI student's follow-up questions.
5. Receive feedback about your understanding.

### Profile
Customize your profile with information such as:
- Your grade level
- School
- Subjects you study
- Learning goals
- Subjects you can teach
- Availability
- A short introduction

## 3. Important Information

- StudyBridge is designed to be accessed through a web browser.
- You do not need to install Node.js or a code editor to use the website.
- An internet connection is required.
- Some AI features require additional server configuration.
- Use a safe password and avoid sharing sensitive personal information.
